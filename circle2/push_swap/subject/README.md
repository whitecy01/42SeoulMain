# Push_swap — 요구사항 정리

> 42Seoul Circle 2 · *Because Swap_push doesn't feel as natural* (Subject Version 10.0)
> 본 문서는 `push_swap.pdf` 과제 명세를 한국어로 정리한 요구사항 문서입니다.

## 1. 개요

제한된 명령어 집합으로 **두 개의 스택**을 조작해 정수를 **최소 연산 횟수**로 정렬하는 알고리즘 과제. 정렬 알고리즘과 **복잡도(complexity)** 를 학습한다.

## 2. 규칙 — 스택과 명령어

- 스택 `a`, `b` 2개. 시작 시 `a`에 중복 없는 정수(음수/양수)가 무작위로, `b`는 비어 있음.
- 목표: 스택 `a`를 **오름차순** 정렬.

| 명령 | 동작 |
|------|------|
| `sa` / `sb` / `ss` | a / b / 둘 다 상위 2개 원소 swap |
| `pa` | b의 top을 a의 top으로 push |
| `pb` | a의 top을 b의 top으로 push |
| `ra` / `rb` / `rr` | a / b / 둘 다 위로 1칸 회전(첫 원소 → 맨 뒤) |
| `rra` / `rrb` / `rrr` | a / b / 둘 다 아래로 1칸 역회전(맨 뒤 → 첫 원소) |

## 3. Mandatory — `push_swap`

| 항목 | 내용 |
|------|------|
| 프로그램명 | `push_swap` |
| 제출 파일 | `Makefile`, `*.h`, `*.c` |
| 인자 | 스택 a: 정수 리스트 |
| 허용 외부 함수 | `read`, `write`, `malloc`, `free`, `exit`, 직접 코딩한 `ft_printf` 류 |
| libft 사용 | 허용 |

**규칙**
- Makefile은 relink 금지. **전역 변수 금지.**
- 인자로 받은 정수 리스트(첫 인자가 스택의 top, 순서 주의)를 정렬하는 **명령어 시퀀스**를 출력.
- 명령은 `\n`으로만 구분.
- **최소 연산**이 목표. 평가 시 연산 수가 허용 한도와 비교됨 → 한도 초과 또는 정렬 실패 시 **0점**.
- 인자가 없으면 아무것도 출력하지 않고 종료.
- 에러 시 표준 에러에 `"Error\n"` 출력. (정수 아님, 정수 범위 초과, 중복 등)

```bash
$> ./push_swap 2 1 3 6 5 8
sa
pb
...
$> ./push_swap 0 one 2 3
Error
```

## 4. 벤치마크 (Benchmark)

평가 시 검증되는 연산 수 기준:
- **100% (보너스 자격 포함)**: 100개 < **700**, 500개 ≤ **5500**.
- **최소 통과 (80%)**: 예) 100개 < 1100 & 500개 < 8500 등 다양한 조합.

> 보너스를 하려면 모든 벤치마크 단계를 최고 점수로 통과해야 함.

## 5. Bonus — `checker` 프로그램

> mandatory가 **완벽(모든 벤치마크 통과 포함)** 할 때만 평가.

| 항목 | 내용 |
|------|------|
| 프로그램명 | `checker` |
| 제출 파일 | `*.h`, `*.c`, Makefile에 `bonus` 규칙 |
| 인자 | 스택 a: 정수 리스트 |

- 인자로 스택 a를 받고(인자 없으면 아무것도 출력 없이 종료), **표준 입력**에서 `\n`으로 끝나는 명령들을 읽어 스택에 실행.
- 실행 후 a가 정렬되고 b가 비었으면 `"OK\n"`, 그 외에는 `"KO\n"` (표준 출력).
- 에러 시 `"Error\n"` (표준 에러). (정수 아님/범위 초과/중복/존재하지 않는 명령 등)
- 제공된 바이너리와 **동일 동작을 재현할 필요는 없음**. 에러 처리는 필수, 파싱 방식은 자유.

## 6. 공통 규칙 & 제출

- 언어 C, **Norm** 준수(보너스 포함). 비정상 종료/메모리 누수 시 0점.
- Makefile은 `cc` + `-Wall -Wextra -Werror`. libft 사용 시 `libft` 폴더 연계.
- 루트에 `README.md` 필수(첫 줄 42 문구, Description/Instructions/Resources+AI 사용 내역).
- 평가용 바이너리 `checker_OS`는 인트라넷 자료에서 제공. 평가 중 간단한 수정 요청 가능.
