# So Long — 요구사항 정리

> 42Seoul Circle 2 · *And thanks for all the fish!* (Subject Version 4.0)
> 본 문서는 `so_long.pdf` 과제 명세를 한국어로 정리한 요구사항 문서입니다.

## 1. 개요

학교 그래픽 라이브러리 **MiniLibX**를 사용해 만드는 간단한 **2D 게임**. 윈도우 관리, 이벤트 처리, 텍스처/스프라이트, 색상 등을 학습한다. 플레이어가 맵의 모든 수집물을 모은 뒤 출구로 탈출하는 게임.

## 2. Mandatory — `so_long`

| 항목 | 내용 |
|------|------|
| 프로그램명 | `so_long` |
| 제출 파일 | `Makefile`, `*.h`, `*.c`, `maps`, `textures` |
| 인자 | `*.ber` 형식의 맵 파일 |
| libft 사용 | 허용 |

**허용 외부 함수**
- `open`, `close`, `read`, `write`, `malloc`, `free`, `perror`, `strerror`, `exit`
- math 라이브러리 전체(`-lm`), MiniLibX 전체 함수, `gettimeofday()`
- 직접 코딩한 `ft_printf` 류

**기본 규칙**
- **MiniLibX 사용 필수** (학교 머신 버전 또는 소스 설치).
- Makefile은 relink 금지. 맵 파일 `.ber`를 인자로 받음.

### 게임 (Game)
- 목표: 맵의 **모든 수집물(collectible)** 을 모은 뒤 출구로 탈출.
- **W, A, S, D** 키로 캐릭터 이동 (상/하/좌/우 4방향). (ZQSD나 방향키도 가능)
- 벽으로는 이동 불가.
- **이동할 때마다 이동 횟수**를 셸에 출력.
- **2D 뷰**(top-down 또는 profile) 사용. 실시간일 필요는 없음. 테마는 자유.

### 그래픽 관리 (Graphic management)
- 이미지를 윈도우에 표시. 윈도우 관리(전환/최소화 등)가 매끄러워야 함.
- **ESC** 키 → 윈도우 닫고 깔끔하게 종료.
- 윈도우 X(닫기) 버튼 클릭 → 깔끔하게 종료.
- **MiniLibX의 이미지(images) 사용 필수.**

### 맵 (Map) — `.ber`
- 구성 요소: 벽, 수집물, 빈 공간. 사용 가능한 문자 **5개만**:
  - `0` 빈 공간, `1` 벽, `C` 수집물, `E` 출구, `P` 플레이어 시작 위치
- 유효 맵 조건: 출구 **1개**, 시작 위치 **1개**, 수집물 **최소 1개**. (출구/시작 중복 시 에러)
- 맵은 **직사각형**이어야 함.
- 맵은 **벽으로 완전히 둘러싸여야** 함. 아니면 에러.
- **유효한 경로(path) 존재 여부를 검증**해야 함.
- 위 규칙을 지키는 한 어떤 맵이든 파싱 가능해야 함.
- 잘못된 설정 발견 시 깔끔하게 종료하고 `"Error\n"` + 명시적 에러 메시지 출력.

```
1111111111111
10010000000C1
1000011111001
1P0011E000001
1111111111111
```

## 3. Bonus

> mandatory가 **완벽**할 때만 평가. (그래픽 과제는 추후에 더 있으니 시간 과투자 금지)

- 적 순찰(enemy patrol)에 닿으면 패배.
- 스프라이트 애니메이션 추가.
- 이동 횟수를 셸 대신 **화면에 직접 표시**.
- 정당화되면 추가 함수 사용 가능. 보너스용 파일/폴더 추가 가능.

## 4. 공통 규칙 & 제출

- 언어 C, **Norm** 준수(보너스 포함). 비정상 종료/메모리 누수 시 0점.
- Makefile은 `cc` + `-Wall -Wextra -Werror`. libft 사용 시 `libft` 폴더 연계.
- 루트에 `README.md` 필수(첫 줄 42 문구, Description/Instructions/Resources+AI 사용 내역).
- 게임 에셋(타일/스프라이트)은 itch.io 등에서 구할 수 있으며 **타인의 저작권 존중**.
- 평가 중 간단한 수정 요청 가능(이해도 검증용).
