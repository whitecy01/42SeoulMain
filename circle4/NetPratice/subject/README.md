# NetPractice — 요구사항 정리

> 42Seoul Circle 4 · *Discover the basics of networking* (Subject Version 5.0)
> 본 문서는 `NetPractice.pdf` 과제 명세를 한국어로 정리한 요구사항 문서입니다.

## 1. 개요

**컴퓨터 네트워킹 기초**를 실습으로 익히는 프로젝트. IP 주소를 설정하고, 라우터를 통해 장치를 연결하고, 네트워크 안에서 **게이트웨이(gateway)** 의 역할을 이해한다. 코드를 작성하는 프로젝트가 아니라, 웹 브라우저에서 열리는 학습 인터페이스로 **소규모 네트워크를 설정**하는 문제 풀이형 과제다.

핵심 개념: **TCP/IP 주소 체계**, **서브넷 마스크(subnet mask)**, **기본 게이트웨이(default gateway)**, 라우터, 스위치.

## 2. 진행 방식

- 프로젝트 페이지에 첨부된 파일을 다운로드 → 임의 폴더에 압축 해제 → 폴더 안의 **`index.html`** 실행 → 웹 브라우저에서 학습 인터페이스가 열림.
- **인트라넷 로그인 입력 필수**: 로그인을 입력하면 본인 전용 구성(personal configuration)으로 연습. (입력하지 않으면 안 됨 — moulinette가 본인 구성을 알아야 함)
- 또는 `Evaluation` 탭으로 랜덤 구성 연습 가능(평가 환경과 유사).
- 다루는 네트워크는 실제 네트워크가 아니라 학습용 가상 네트워크.

## 3. Mandatory part — 10개 레벨

총 **10개 레벨(10개 연습 문제)** 를 풀어야 한다.

- 각 레벨마다 **정상 동작하지 않는 네트워크 다이어그램**이 제시된다.
- 화면 상단에 하나 이상의 **목표(goal)** 가 표시됨(예: host A가 host B와 통신해야 함).
- **음영 없는(unshaded) 필드만 수정**하여 네트워크가 정상 동작하도록 구성한다.
- 버튼:
  - **[Check again]**: 구성이 올바른지 검증.
  - **[Get my config]**: 현재 구성을 파일로 내보내기(제출에 사용).
- 레벨을 성공하면 **[Next level]** 버튼이 나타나 다음 레벨로 이동.
- 페이지 하단의 **로그(logs)** 를 통해 무엇이 잘못됐는지 파악 가능(게이트웨이 누락, 잘못된 IP 등).

> ⚠️ 다음 레벨로 넘어가기 전 반드시 **[Get my config]** 로 구성을 내보내 Git 저장소에 보관할 것.

## 4. README 요구사항

저장소 루트에 `README.md` 필수. 최소 포함 항목:
- **첫 줄(이탤릭)**: `This project has been created as part of the 42 curriculum by <login1>[, <login2>...].`
- **Description**: 프로젝트 목표·개요.
- **Instructions**: 학습 인터페이스 실행법(`index.html` 열기), 구성 내보내기 방법, 제출 요건.
- **Resources**: 학습한 네트워킹 개념(TCP/IP 주소 체계, 서브넷 마스크, 기본 게이트웨이, 라우터·스위치, OSI 계층 등) 명시 + AI를 어떤 작업/부분에 어떻게 사용했는지 기술.
- **제출 명세**: 레벨당 1개씩 **10개의 내보낸 구성 파일**을 저장소 루트에 둔다는 점을 명시.

## 5. 제출 및 평가

- Git 저장소에 제출. **레벨당 1파일, 총 10개 파일을 저장소 루트**에 둔다. 파일명 정확히 확인.
- 인터페이스에 **반드시 본인 로그인 입력** 후 [Get my config]로 레벨별 파일 내보내기.
- 디펜스에서 **랜덤 3개 레벨**을 제한 시간 내에 성공해야 함.
- 평가 중 **외부 도구 사용 금지**. `bc` 같은 단순 계산기까지만 허용.
