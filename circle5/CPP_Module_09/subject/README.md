# C++ Module 09 — 요구사항 정리

> 42Seoul Circle 5 · *STL* (Subject Version 3.0)
> 본 문서는 `CPP Module 09.pdf` 과제 명세를 한국어로 정리한 요구사항 문서입니다.

## 1. 개요

**STL(Standard Template Library)** 을 본격 활용한다. 표준 컨테이너를 골라 실제 문제(환율 계산, RPN 계산기, 정렬 알고리즘)에 적용하는 것이 핵심이다.

## 2. 공통 규칙 (요약)

CPP 모듈 공통 규칙 적용 ([Module 00 README](../../../circle4/CPP_Module_00/subject/README.md) 참고). Module 02~09 모든 클래스 **Orthodox Canonical Form**. STL은 Module 08·09에서만 허용.

**모듈 특화 규칙 (필수)**:
- 각 연습은 **반드시 표준 컨테이너를 사용**해서 풀어야 한다.
- **한 번 사용한 컨테이너는 이 모듈의 나머지 연습에서 다시 쓸 수 없다.**
- ex00·ex01은 **최소 1개**, **ex02는 서로 다른 2개**의 컨테이너 사용 필수.
- 각 프로그램마다 `Makefile` 제출(`-Wall -Wextra -Werror`, relink 금지, 규칙 `$(NAME)`/`all`/`clean`/`fclean`/`re`).

## 3. Exercises

### ex00 — Bitcoin Exchange
- 파일: `Makefile`, `main.cpp`, `BitcoinExchange.{cpp,hpp}` / 금지 함수: 없음
- 프로그램명 `btc`. 특정 날짜의 비트코인 가치를 출력.
- 함께 제공되는 **csv 데이터베이스**(시간에 따른 BTC 가격)를 사용.
- 인자로 **입력 파일**을 받음. 각 줄 형식: `"date | value"`.
  - 날짜: `Year-Month-Day` 형식.
  - 값: float 또는 양의 정수, **0 ~ 1000** 범위.
- 입력의 값 × 해당 날짜의 환율 결과를 표준 출력에 표시.
- **DB에 해당 날짜가 없으면 가장 가까운 날짜(단, 더 낮은/이전 날짜) 사용.**
- 에러는 적절한 메시지로 처리:
  - 파일 못 열면 `Error: could not open file.`
  - 음수 값 `Error: not a positive number.`
  - 1000 초과 `Error: too large a number.`
  - 잘못된 형식 `Error: bad input => <입력>`
- **최소 1개 컨테이너 사용 필수.** (여기서 쓴 컨테이너는 이후 연습에서 사용 불가)

### ex01 — Reverse Polish Notation
- 파일: `Makefile`, `main.cpp`, `RPN.{cpp,hpp}` / 금지 함수: 없음
- 프로그램명 `RPN`. **역폴란드 표기식**을 인자로 받아 계산 결과를 표준 출력에 표시.
- 인자로 주어지는 숫자는 항상 **10 미만**(계산 과정·결과는 이 제약 무관).
- 지원 토큰: `+ - / *`. **괄호·소수 처리 불필요.**
- 에러 발생 시 표준 에러에 에러 메시지 출력(`Error`).
- 예: `./RPN "8 9 * 9 - 9 - 9 - 4 - 1 +"` → `42`.
- **최소 1개 컨테이너 사용 필수.** (ex00에서 쓴 컨테이너 금지, 여기서 쓴 것도 이후 금지)

### ex02 — PmergeMe
- 파일: `Makefile`, `main.cpp`, `PmergeMe.{cpp,hpp}` / 금지 함수: 없음
- 프로그램명 `PmergeMe`. **양의 정수 시퀀스**를 인자로 받아 정렬.
- **merge-insert sort(Ford-Johnson 알고리즘)** 사용 필수.
- 에러 발생 시 표준 에러에 메시지 출력(`Error`).
- 출력(줄 단위):
  1. 설명 텍스트 + 정렬 전 시퀀스 (`Before: ...`)
  2. 설명 텍스트 + 정렬 후 시퀀스 (`After: ...`)
  3. **첫 번째 컨테이너**로 정렬하는 데 걸린 시간(어떤 컨테이너인지 명시)
  4. **두 번째 컨테이너**로 정렬하는 데 걸린 시간(어떤 컨테이너인지 명시)
- 시간 표시 형식은 자유지만 **두 컨테이너 차이가 명확히 보일 정밀도** 필요. 시간은 정렬+데이터 관리 전체를 측정.
- **서로 다른 컨테이너 2개 사용 필수**, **최소 3000개** 정수 처리 가능해야 함.
- 컨테이너별로 알고리즘을 각각 구현하는 것 권장(제네릭 함수 회피). 중복 처리는 자유.
